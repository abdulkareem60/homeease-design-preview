Design preview only. Sample products, prices and stock. v3 uses licensed stock photographs (Unsplash) as stand-ins for real product photos; v1 and v2 use drawn sample renders. WhatsApp actions show a message preview; checkout is outside this phase. Nothing is sent, charged or recorded.

What changed in v3 (revised) compared with v2 (previous)

  • Real photography: drawn product renders replaced with licensed photographs (Unsplash License). The sample catalogue was rebuilt around the photos so each product's name, colour and visible features match what is shown. Gallery close-ups are crops of the same photograph, never a different product. Crops use a focal point per product so the item stays visible on phone and desktop.
  • Typography: Red Hat Display for headings and prices, Red Hat Text for body copy and controls, Red Hat Mono for Direction B's specifications. Tighter heading spacing, consistent sizes on desktop and mobile, and lining tabular figures so PKR prices line up.
  • Catalogue changes (sample data): 8 products matching available photos. The jewellery box is shown in one colour (Blush Pink) because both photos are of the same pink box; colour choice is demonstrated on the Cotton Bath Towel (White, Charcoal sold out), each colour shown as a crop of that towel.
  • Unchanged: layouts, cart, WhatsApp previews, availability modes and the v2 product-page improvements.
